Exercise 03: Replace Send/Recv with Gather

1. OBJECTIVE & CODE REFACTORING DETAILS:
--------------------------------------------------------------------------------
In Exercise 2, partial sums were collected on the root process using a manual loop
of MPI_Send / MPI_Recv calls. This point-to-point approach requires O(P) sequential
steps where root serially posts receives from each rank.

Key modifications made in sum_gather.c:
1. Replaced the point-to-point Send/Recv logic with MPI_Gather:
   MPI_Gather(&local_sum, 1, MPI_LONG_LONG, all_sums, 1, MPI_LONG_LONG, 0, MPI_COMM_WORLD);
2. Buffer Management:
   - On root (rank 0), allocated `all_sums` array of size `size` elements (type `long long`).
   - On non-root ranks, `all_sums` remains NULL as recvbuf is only inspected at root.
3. Summation on Root:
   After MPI_Gather completes, root loops over `all_sums[0 .. size-1]` to compute
   `total_sum`.
4. Collective Communication Advantages:
   MPI_Gather eliminates manual point-to-point message matching, avoids potential
   head-of-line blocking or deadlocks, and allows the MPI runtime to use optimized
   tree-structured data collection.

2. SOURCE CODE (sum_gather.c):
--------------------------------------------------------------------------------
#include <mpi.h>
#include <stdio.h>
#include <stdlib.h>

#define N 1000000

int main(int argc, char **argv) {
    MPI_Init(&argc, &argv);
    int rank, size;
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);

    int chunk_size = N / size;

    /* Only root allocates the full array */
    int *array = NULL;
    if (rank == 0) {
        array = (int *)malloc(N * sizeof(int));
        if (array == NULL) {
            fprintf(stderr, "Root failed to allocate full array\n");
            MPI_Abort(MPI_COMM_WORLD, 1);
        }
        for (int i = 0; i < N; i++)
            array[i] = i + 1;
        printf("Root filled array with values 1 to %d\n", N);
    }

    /* All processes allocate only their small local chunk */
    int *local_chunk = (int *)malloc(chunk_size * sizeof(int));
    if (local_chunk == NULL) {
        fprintf(stderr, "Rank %d failed to allocate local_chunk\n", rank);
        MPI_Abort(MPI_COMM_WORLD, 1);
    }

    double start = MPI_Wtime();

    /* Distribute chunks using Scatter */
    MPI_Scatter(array, chunk_size, MPI_INT,
                local_chunk, chunk_size, MPI_INT,
                0, MPI_COMM_WORLD);

    /* Local summation */
    long long local_sum = 0;
    for (int i = 0; i < chunk_size; i++)
        local_sum += local_chunk[i];

    int start_idx = rank * chunk_size;
    int end_idx = start_idx + chunk_size;
    printf("  Rank %d: summed indices [%d, %d) => local_sum = %lld\n",
           rank, start_idx, end_idx, local_sum);

    /*
     * GATHER: Collect partial sums from all processes into all_sums[] on root.
     * On root, allocate an array for size elements.
     */
    long long *all_sums = NULL;
    if (rank == 0) {
        all_sums = (long long *)malloc(size * sizeof(long long));
        if (all_sums == NULL) {
            fprintf(stderr, "Root failed to allocate all_sums\n");
            MPI_Abort(MPI_COMM_WORLD, 1);
        }
    }

    MPI_Gather(&local_sum, 1, MPI_LONG_LONG,
               all_sums, 1, MPI_LONG_LONG,
               0, MPI_COMM_WORLD);

    /* On root, loop through gathered all_sums to compute total */
    if (rank == 0) {
        long long total_sum = 0;
        for (int r = 0; r < size; r++) {
            total_sum += all_sums[r];
        }

        double elapsed = MPI_Wtime() - start;
        long long expected = (long long)N * (N + 1) / 2;
        printf("\n[Gather] Total sum   = %lld\n", total_sum);
        printf("[Gather] Expected    = %lld\n", expected);
        printf("[Gather] Correct?    = %s\n", total_sum == expected ? "YES" : "NO");
        printf("[Gather] Time        = %.4f sec\n", elapsed);

        free(all_sums);
    }

    if (rank == 0) free(array);
    free(local_chunk);
    MPI_Finalize();
    return 0;
}
