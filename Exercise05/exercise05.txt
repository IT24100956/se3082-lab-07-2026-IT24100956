Exercise 05: Replace Reduce with Allreduce

1. OBJECTIVE & CODE REFACTORING DETAILS:
--------------------------------------------------------------------------------
In Exercise 4, MPI_Reduce delivered the grand total strictly to root. In many real-world
algorithms (such as iterative solvers, normalization, standard deviation calculations,
or calculating percentage contributions), every process needs the global reduced value.
Instead of doing MPI_Reduce followed by an extra MPI_Bcast, MPI_Allreduce computes the
reduction and distributes the answer to all ranks in a single collective call.

Key modifications made in sum_allreduce.c:
1. Replaced MPI_Reduce with MPI_Allreduce:
   MPI_Allreduce(&local_sum, &total_sum, 1, MPI_LONG_LONG, MPI_SUM, MPI_COMM_WORLD);
   Note: MPI_Allreduce does not accept a `root` parameter.
2. Contribution Percentage Calculation on EVERY process:
   double percentage = ((double)local_sum / (double)total_sum) * 100.0;
   Every rank prints its local_sum, global total_sum, and contribution percentage.
3. Verification check:
   Root verifies that total_sum == 500,000,500,000.

2. SOURCE CODE (sum_allreduce.c):
--------------------------------------------------------------------------------
#include <mpi.h>
#include <stdio.h>
#include <stdlib.h>

#define N 1000000

int main(int argc, char **argv) {
    MPI_Init(&argc, &argv);
    int rank, size;
    MPI_Comm_rank(MPI_COMM_WORLD, &rank);
    MPI_Comm_size(MPI_COMM_WORLD, &size);

    int chunk_size = N / size;

    /* Only root allocates the full array */
    int *array = NULL;
    if (rank == 0) {
        array = (int *)malloc(N * sizeof(int));
        if (array == NULL) {
            fprintf(stderr, "Root failed to allocate full array\n");
            MPI_Abort(MPI_COMM_WORLD, 1);
        }
        for (int i = 0; i < N; i++)
            array[i] = i + 1;
        printf("Root filled array with values 1 to %d\n", N);
    }

    /* All processes allocate only their small local chunk */
    int *local_chunk = (int *)malloc(chunk_size * sizeof(int));
    if (local_chunk == NULL) {
        fprintf(stderr, "Rank %d failed to allocate local_chunk\n", rank);
        MPI_Abort(MPI_COMM_WORLD, 1);
    }

    double start = MPI_Wtime();

    /* Distribute chunks using Scatter */
    MPI_Scatter(array, chunk_size, MPI_INT,
                local_chunk, chunk_size, MPI_INT,
                0, MPI_COMM_WORLD);

    /* Local summation */
    long long local_sum = 0;
    for (int i = 0; i < chunk_size; i++)
        local_sum += local_chunk[i];

    /*
     * ALLREDUCE: Reduces local values across all processes using MPI_SUM,
     * and broadcasts the result to EVERY process in a single collective call.
     */
    long long total_sum = 0;
    MPI_Allreduce(&local_sum, &total_sum, 1, MPI_LONG_LONG,
                  MPI_SUM, MPI_COMM_WORLD);

    /*
     * EVERY process now has total_sum.
     * Each process computes and prints its percentage contribution.
     */
    double percentage = ((double)local_sum / (double)total_sum) * 100.0;
    printf("  Rank %d: local_sum = %lld, total_sum = %lld, contribution = %.2f%%\n",
           rank, local_sum, total_sum, percentage);

    /* Verification output on root */
    if (rank == 0) {
        double elapsed = MPI_Wtime() - start;
        long long expected = (long long)N * (N + 1) / 2;
        printf("\n[Allreduce] Total sum   = %lld\n", total_sum);
        printf("[Allreduce] Expected    = %lld\n", expected);
        printf("[Allreduce] Correct?    = %s\n", total_sum == expected ? "YES" : "NO");
        printf("[Allreduce] Time        = %.4f sec\n", elapsed);
    }

    if (rank == 0) free(array);
    free(local_chunk);
    MPI_Finalize();
    return 0;
}
